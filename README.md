# Smart WaterWorks - ระบบบริหารจัดการและจัดเก็บข้อมูลผู้ใช้น้ำประปา

เว็บแอปพลิเคชันระบบบริหารจัดการและจัดเก็บข้อมูลผู้ใช้น้ำประปาชุมชนและท้องถิ่น (Village & Local Waterworks Consumer Management System) ครบวงจร ทั้งการบันทึกทะเบียนผู้ใช้น้ำ การเดินจดมิเตอร์ประจำเดือน การคำนวณค่าน้ำแบบขั้นบันไดอัตโนมัติ การออกใบแจ้งหนี้พร้อม QR Code พร้อมเพย์ (PromptPay QR) การบันทึกรับชำระเงิน การออกใบเสร็จรับเงิน และรายงานสถิติหนี้ค้างชำระ

---

## 🌟 ฟังก์ชันหลักของระบบ (Key Features)

### 1. 📊 ภาพรวมระบบและสถิติ (Dashboard)
- สรุปตัวเลขสำคัญ: จำนวนผู้ใช้น้ำทั้งหมด, ความคืบหน้าการจดมิเตอร์เดือนปัจจุบัน, ปริมาณการใช้น้ำ (ลบ.ม.), ยอดเงินเรียกเก็บ, ยอดเงินที่จัดเก็บได้ และหนี้ค้างชำระ
- กราฟแท่งวิเคราะห์เปรียบเทียบปริมาณน้ำและรายรับย้อนหลัง 6 เดือน
- แผนภูมิสัดส่วนประเภทผู้ใช้น้ำ (บ้านพักอาศัย, ธุรกิจ/ร้านค้า, สถานที่ราชการ, เกษตรกรรม)
- ระบบแจ้งเตือนความผิดปกติอัตโนมัติ (เช่น ใช้น้ำสูงผิดปกติท่ออาจรั่วซึม, มิเตอร์ไม่หมุน 0 หน่วย)
- ประวัติการทำรายการล่าสุด (Audit Trail)

### 2. 👥 ทะเบียนผู้ใช้น้ำ (Water Users Directory)
- จัดการข้อมูลผู้ใช้น้ำอย่างละเอียด: รหัสผู้ใช้น้ำ (W-xxxx), ชื่อ-นามสกุล, เลขบัตร ปชช., เบอร์โทร, บ้านเลขที่, หมู่ที่, ตำบล, อำเภอ, จังหวัด
- ข้อมูลมิเตอร์: หมายเลขมิเตอร์, ขนาดท่อ (1/2", 3/4", 1"), เลขมิเตอร์ตั้งต้น, วันที่ติดตั้ง, พิกัด GPS
- ค้นหาและกรองข้อมูลได้ทันที (Live Instant Search) ตามชื่อ, รหัส, บ้านเลขที่, หมายเลขมิเตอร์, สายการจด (Zone), ประเภท และสถานะ
- ดูประวัติรายบุคคล: แสดงประวัติการจดมิเตอร์ย้อนหลังทุกเดือน และประวัติการชำระเงิน
- **พิมพ์ป้าย QR Code ประจำมิเตอร์**: สำหรับนำไปติดที่หน้าปัดมิเตอร์ ให้สแกนตรวจสอบข้อมูลหรือชำระเงินได้ทันที
- ส่งออกข้อมูลเป็นไฟล์ Excel / CSV

### 3. 📝 ระบบจดมิเตอร์น้ำประจำเดือน (Monthly Meter Reading)
- เลือกรอบเดือนและสายการเดินจด (Route / Zone)
- คำนวณปริมาณหน่วยที่ใช้ (Units Used) ทันทีแบบ Real-time เมื่อป้อนเลขหน้าปัด
- ระบบตรวจสอบความถูกต้อง: แจ้งเตือนทันทีหากตัวเลขน้อยกว่าครั้งก่อน หรือหากตัวเลขสูงผิดปกติ
- บันทึกแบบรายคน หรือกด **"บันทึกข้อมูลทั้งหมด" (Batch Save)**
- ระบบคำนวณค่าน้ำและสร้างใบแจ้งหนี้ให้อัตโนมัติทันทีที่บันทึก

### 4. 📱 โหมดเดินจดสนามด้วยมือถือ (Mobile Field Reader Mode)
- หน้าจอออกแบบพิเศษสำหรับการถือสมาร์ทโฟนเดินจดมิเตอร์ตามบ้าน
- แสดงข้อมูลบ้านทีละหลังด้วยการ์ดขนาดใหญ่ ตัวเลขชัดเจน กดง่าย
- ปุ่ม "บันทึกและไปบ้านถัดไป" อัตโนมัติ เลื่อนลำดับตามสายเดินจดในหมู่บ้านอย่างรวดเร็ว

### 5. 🧾 ระบบออกบิลและใบแจ้งหนี้ (Billing & Invoicing)
- รายการใบแจ้งหนี้ประจำรอบเดือน ค้นหาและกรองตามสถานะ (รอชำระ, ชำระแล้ว, เกินกำหนด)
- **ใบแจ้งหนี้มาตรฐาน (Printable Invoice)**: รูปแบบเอกสารมาตรฐาน แสดงรายละเอียดมิเตอร์ อัตราค่าน้ำ ค่าบำรุงมิเตอร์ และภาษี
- **PromptPay QR Code แบบ Dynamic**: สแกนจ่ายด้วยแอปพลิเคชันทุกธนาคาร ยอดเงินตรงตามบิล
- **ระบบพิมพ์ใบแจ้งหนี้แบบชุด (Bulk Print)**: สั่งพิมพ์ใบแจ้งหนี้ทั้งสาย/ทั้งหมู่บ้านได้ในคลิกเดียว เพื่อนำไปแจกจ่ายตามตู้จดหมาย

### 6. 💳 ระบบบันทึกรับชำระเงินและออกใบเสร็จ (Payment & Receipting)
- บันทึกการรับเงินทั้งแบบเงินสด (พร้อมระบบคำนวณเงินทอนอัตโนมัติ) และแบบสแกน PromptPay QR
- เอฟเฟกต์ฉลองเมื่อชำระเงินสำเร็จ (Confetti)
- **ใบเสร็จรับเงินอย่างเป็นทางการ (Official Receipt)**: แสดงเลขที่ใบเสร็จ, ตรายางประทับชำระแล้ว (PAID), วันที่เวลาชำระ และชื่อเจ้าหน้าที่ผู้รับเงิน

### 7. 📈 รายงานและติดตามหนี้ค้างชำระ (Reports & Overdue Management)
- รายงานสรุปปริมาณน้ำและรายรับประจำเดือน แยกตามสายการจดและประเภทผู้ใช้
- **รายงานลูกหนี้ค้างชำระ**: แสดงรายชื่อผู้ใช้น้ำที่ค้างชำระเกินกำหนด ยอดหนี้รวม และจำนวนบิลที่ค้าง
- **ระบบออกหนังสือเตือนชำระหนี้ค่าน้ำประปา**: พิมพ์หนังสือราชการแจ้งเตือนผู้ใช้น้ำรายบุคคลได้ทันที

### 8. ⚙️ ตั้งค่าระบบ (Settings & Configuration)
- กำหนดชื่อหน่วยงาน, ที่อยู่, เบอร์โทรศัพท์, เลขประจำตัวผู้เสียภาษี
- กำหนดหมายเลขพร้อมเพย์ (เบอร์โทร หรือ เลขประจำตัว 13 หลัก)
- ปรับเปลี่ยนอัตราค่าน้ำแบบขั้นบันได (Tiered Tariffs) และค่าบริการมิเตอร์รายเดือน
- สำรองข้อมูลระบบทั้งหมดเป็นไฟล์ JSON (Backup)
- ปุ่มรีเซ็ตและโหลดข้อมูลตัวอย่างเสมือนจริง (Reset & Seed Demo Data)

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

- **Frontend**: React 19, Tailwind CSS, Vite, Lucide Icons, Canvas Confetti, QRCode
- **Backend**: Node.js, Express.js
- **Database**: SQLite (better-sqlite3) with WAL Mode
- **Standards**: EMVCo QR Code Payload with CRC16-CCITT for Thai PromptPay

## 🚀 วิธีการติดตั้งและรันระบบ (Getting Started)

```bash
# 1. ติดตั้ง Dependencies
npm install

# 2. คอมไพล์ Frontend (Vite)
npm run build

# 3. เริ่มต้นเซิร์ฟเวอร์
npm start
```

เปิดเบราว์เซอร์ไปที่: `http://localhost:3000`
